# Dansk — landing page (Next.js)

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

- Default language is English; EN / UA / RU switcher in the header (choice is remembered in localStorage).
- All copy lives in `app/translations.js`.
- Contact details: `CONTACTS` at the top of `app/Landing.js`.
- Photos: replace files in `public/images/` (hero.jpg, anna.jpg, notebook.jpg).
